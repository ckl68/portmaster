## Publish updates
Upload **the contents of this folder**, not the containing folder, to the root of the `ckl68/Drayage` GitHub repository. Replace `index.html`, `styles.css`, `script.js`, and the `assets/` files (including `kyle-samin-ceo.webp`) with these files. Commit changes and check GitHub **Actions** for deployment.

Your website is https://ckl68.github.io/Drayage/

## Quote form
The quote form uses `mailto:` to open the visitor's email app with a prefilled request addressed to service@portmaster.com. It **does not send inquiries automatically**. A form backend is required for direct submission.

## Homepage image
The homepage uses `assets/portmaster-main-truck.jpg`, supplied by the site owner, rather than the original SVG truck illustration. Preserve the `assets` directory when uploading.
